- IP: `marchtaylor.ddns.net:25565`

- `polymer-bundled`

## Dev запуск сервера
- Команда запуска: `cd ~/Desktop/lostglade/mods/lg2-0.1.0 && ./gradlew runServer`
- Скрипт запуска: `cd ~/Desktop/lostglade/mods/lg2-0.1.0 && ./scripts/run-dev-server.sh`
- `runServer` запускается из корня сервера: `~/Desktop/lostglade`

## Защита офлайн-аккаунтов

В мод встроена регистрация и проверка лицензионных сессий. На offline-сервере
мод повторяет vanilla encryption handshake и принимает premium-вход только
после ответа Mojang `hasJoinedServer`, а не по UUID, который прислал клиент.
До успешной проверки игрок помещается в закрытую чёрную ячейку 1×2 из
`startup_void`; ему отправляется только её чанк, а движение, инвентарь и
взаимодействия заблокированы. Ячейка восстанавливает исходные блоки при входе
или отключении, поэтому не меняет стартовую сцену.
Подсказка показывается только в actionbar и локализована для `en_us`, `ru_ru`,
`uk_ua`, `ja_jp` и `rpr`:

- при первом входе напишите придуманный пароль прямо в чат;
- с нового IP без клиентского мода напишите свой пароль прямо в чат;
- лицензионный клиент, подтвердивший Mojang-сессию, входит без пароля;
- если лицензионный ник приходит без подтверждённой сессии, сервер сверяется
  с Mojang и резервирует ник. До `/password <новый_пароль> <игрок>` от
  администратора вход без лицензии невозможен; старые IP и токены не годятся;
- `/password <новый_пароль>` доступна всегда: до входа работает как ввод
  пароля, после входа меняет пароль.
- администратор может восстановить игроку пароль командой
  `/password <новый_пароль> <игрок>`; это отзывает старые IP и клиентские токены.

Успешный пароль добавляет IP в доверенные. Клиентский `lg2-client` сохраняет
случайный локальный секрет в `config/lostglade-auth.json`; после первой
регистрации он позволяет входить с другого IP без ввода пароля. Сервер хранит
PBKDF2-хэш пароля, хэш секрета и хэши IP в `config/lg2-auth.json`, а не сами
пароли и токены. После пяти неверных попыток вход блокируется на минуту.
Если Mojang временно недоступен именно во время первой проверки имени, новая
регистрация этого имени блокируется до следующей попытки, а не открывает
возможность захвата лицензионного ника.

## Серверный ресурспак
- Исходник пустого pack хранится как папка: `mods/lg2-0.1.0/resourcepack/`
- Перед запуском gradle-задача `prepareDevResourcePack` копирует его в `polymer/source_assets/`
- Polymer AutoHost включён в `config/polymer/auto-host.json`, поэтому клиенту предлагается загрузка ресурспака при заходе

## Языки
- названия предметов/блоков отображается даже когда нет ресурспака
- языки: ru_ru, rpr, uk_ua, ja_jp, en_us (default)
